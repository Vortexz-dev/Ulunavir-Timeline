# Olay sesleri — kaynaklar ve lisanslar / Event sounds — sources and licences

Only the 40 important events listed in `assets/music.js` (`eventSfx`) play a sound; every other card is silent.
Each `evt-*.mp3` was built for its event by layering, pitching, filtering, reverberating and mixing the recordings below
(ffmpeg + numpy; the build scripts are kept outside this repo), then faded, loudness-normalised to match the
previous site SFX (~-17.5 dB active RMS), mono MP3 96 kbps, 5–6 s. No melodic notes, no frog/swamp sounds.

Licences were checked on each source page (Wikimedia Commons via its API; OpenGameArt on the content page).
- **CC0 / Public domain**: no attribution required; credited anyway.
- **CC BY 3.0 / 4.0** (attribution REQUIRED, all modified as described above): Gregor Quendel — “Free Crowd Cheering Sounds” (CC BY 4.0);
  Kat — “Scary Echoey Horn Esque Sound” (CC BY 4.0); Michel Baradari — “15 monster grunt/pain/death sounds”, “2 High Quality Explosions”,
  “Rumble/explosion” (CC BY 3.0); congusbongus — “Aargh! (male screams)”, “Female screams” (CC BY 3.0); pla1554alaska — “Bald Eagle Screams”
  (CC BY 3.0); thanvannispen — “2 takes bats” (CC BY 3.0). Licence texts: https://creativecommons.org/licenses/by/3.0/ and https://creativecommons.org/licenses/by/4.0/

Background ambience: none at the moment (all previous ambience loops were removed; per-era files will be added via `eraAmbience` in `assets/music.js`).
